## Production corrections exposed by the new tests

1. Git `Interrupted` is a terminal timeout/cancellation, not permission to start a
   fallback clone. Already-cancelled synchronous tools do not spawn.
2. After lease-denial cleanup, a poll can redeliver the still-unexpired action.
   A claimed non-create action without a restorable owned workspace is refused
   locally, rather than posting an unknown-job result after ownership was lost.
   The regression replays the claim and asserts no new execution/result.

These corrections do not change public schema bytes. They do change runtime
behavior, so the released pair must be updated through reviewed release/pin
alignment before #17 is declared delivered.
