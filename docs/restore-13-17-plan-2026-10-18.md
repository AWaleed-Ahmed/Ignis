## Resource model and failure boundaries

A tenant owns jobs; a job has an immutable wall deadline and one pending
action. An authenticated connector credential owns an opaque persisted claim
for that action. Claims carry expiry, fixed action/job deadlines and renewal
sequence. Renewal cannot change absolute limits or transfer ownership.
A connector identity is derived from its configured bearer credential; distinct
connectors require distinct credentials. Credential values must never enter
persisted state or logs.

Poll/claim/renewal/result commit/reaping use a shared transaction boundary.
Slow agent hooks run outside it. Final commit revalidates the live action and
expiry, including expiry during persistence. Publication records durable intent
before the remote call and refuses automatic replay after an uncertain result.
The controller receives the execution deadline and independently bounds work;
client disconnection alone does not establish server cancellation.
